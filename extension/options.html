📋 Prerequisites

Install these before using the extension:

⚠️ IMPORTANT: Native Host Installation (Required First)
The extension cannot start servers without this step!

Step 1: Download Installer
Step 2: Run the Installer
macOS / Linux:
1. Open Terminal
2. Navigate to Downloads: cd ~/Downloads
3. Run: bash install_host.sh

Windows:
1. Open Command Prompt
2. Navigate to Downloads: cd %USERPROFILE%\Downloads
3. Run: install_host.bat

Step 3: Reload Extension
Go to chrome://extensions and click the reload icon for LocatorLens

What this does: Installs the native messaging host that allows the extension to start and manage servers.
1. Node.js (v18+)
Download from nodejs.org
2. Appium Server
npm install -g appium
3. Appium Drivers
Android: appium driver install uiautomator2
iOS: appium driver install xcuitest
4. Platform Tools
Android: ADB (via Android Studio)
iOS: Xcode (macOS only)

❓ Help

Quick Start:
1. Install Node.js and run the native host installation script (see important step above)
2. Install Appium and other prerequisites
3. Reload this extension in Chrome
4. Click "Start Servers" in extension popup
5. Select device and click Connect
6. Inspect elements in the Inspector tab
