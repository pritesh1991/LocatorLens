📋 Prerequisites

Install these before using the extension:

1. Node.js (v18+)
Download from nodejs.org
2. Appium Server
npm install -g appium
3. Appium Drivers
Android: appium driver install uiautomator2
iOS: appium driver install xcuitest
4. Platform Tools
Android: ADB (via Android Studio)
iOS: Xcode (macOS only)

❓ Help

Quick Start:
1. Install prerequisites above
2. Click "Start Servers" in extension popup
3. Select device and click Connect
4. Inspect elements in the Inspector tab
