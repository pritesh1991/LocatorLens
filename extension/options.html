LocatorLens

Real-time Element Inspector & Locator Builder for Appium

One-time Setup Required

LocatorLens requires a native companion to start servers. Follow the steps below to get started.

Setup Guide

  • Install Prerequisites
    Node.js v18+ Required to run the backend server
    nodejs.org
    Appium Mobile automation server
    npm install -g appium
    Android Driver For Android devices
    appium driver install uiautomator2
    iOS Driver (macOS only) For iOS simulators
    appium driver install xcuitest
    ADB (Android) Via Android Studio or
    Platform Tools
    Xcode (iOS/macOS) Required for iOS simulator support
    From Mac App Store
  • Download & Run the Native Host Installer

    This registers a helper that lets the extension start servers.

    Then open Terminal and run:

    cd ~/Downloads
bash install_host.sh

    Then open Command Prompt and run:

    cd %USERPROFILE%\Downloads
install_host.bat
  • Reload the Extension

    Go to chrome://extensions, find LocatorLens, and click the reload icon.

  • Connect Your Device

    Click the LocatorLens icon → Start Servers → Select Platform → Select Device → Connect.

Troubleshooting

Issue Solution
"Native messaging host not found" Re-run install_host.sh and reload extension
Servers won't start Check logs in extension popup. Ensure Node.js is installed.
Appium not found npm install -g appium
No Android devices Check adb devices in terminal. Enable USB debugging.
No iOS simulators Boot a simulator in Xcode. macOS only.

Logs saved to: ~/.locatorlens/native-host.log
